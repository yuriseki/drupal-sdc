# Code Instruction Repository

This folder serves as the central communication hub for inter-agent interactions in the SDC development system. All agents share outputs here for coordination, validation, and implementation.

## File Naming Convention
- Files follow the format: `NNN-component-description.md`, where:
  - `NNN` is a sequential number (e.g., 001, 002).
  - `component-description` is a short description of the component (e.g., `cta-component`).
- Include the Figma URL in the documentation.
- Reports from agents (e.g., `drupal-best-practices-report.md`, `code-architecture-analysis.md`) are also stored here.

## Index of Outputs
- 001-component-description.md: Figma extraction and SDC instructions for activity-chart component.
- 002-codebase-analysis.md: Codebase analysis for SDC alignment.
- 003-drupal-best-practices.md: Drupal SDC best practices research.
- 004-sdc-validation.md: SDC compliance validation report.
- 005-revised-instructions.md: Revised SDC instructions with fixes.
- 006-implementation-summary.md: Implementation summary for activity-chart component.

## Guidelines
- Agents should update this README with new entries after generating files.
- If uncertainties arise, flag issues here for human review.
